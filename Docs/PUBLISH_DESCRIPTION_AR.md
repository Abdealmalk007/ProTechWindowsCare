# ProTech Windows Care 3.3.0 — Portable Preview

**برنامج متكامل لفحص وصيانة Windows — يعمل Portable مباشرة دون الحاجة إلى التثبيت.**

شغّل `ProTech_Windows_Care_Setup.exe` مباشرة من سطح المكتب أو USB؛ لا تحتاج إلى تثبيت. إذا أردت تثبيته، يمكنك استخدام `--setup-ui` اختياريًا.

### المميزات
- واجهة عربية/إنجليزية مع أيقونات وأزرار ملونة حسب الوظيفة.
- تحديد الكل، عكس التحديد، إلغاء التحديد، وحماية البرامج النظامية التي لا يجوز حذفها.
- اختيار مجموعة من البرامج لتنفيذ `WinGet Install / Upgrade / Uninstall`، أو حذف تطبيقات AppX الاختيارية ضمن قائمة السماح.
- عرض دقيق للأوامر وآثارها قبل التنفيذ، ونسخة احتياطية موثقة بـSHA-256، ثم موافقة المستخدم وطلب صلاحيات UAC.
- إنشاء نقطة System Restore جديدة والتحقق منها قبل بدء أي دفعة تعديلات. يتوقف التنفيذ عند تعذر الإنشاء.
- تشغيل الدفعة عبر Windows PowerShell، وإظهار عدد العناصر المنجزة، وتسجيل الفشل والتوقف عند نقطة آمنة.
- تقارير التشخيص والخصوصية والأجهزة وBIOS/BSOD والتخزين والتحديثات.

**قيود مهمّة:** نسخة **Portable Preview** — مسارات تحديث/إزالة التطبيقات مبرمجة ومتصلة بالأزرار، لكن لم تُختبر على برامج حقيقية داخل VM. لا تضمن نقطة الاستعادة أو Backup هوية البرنامج إعادة بياناته بعد الحذف. Windows قد يمنع إنشاء أكثر من نقطة استعادة واحدة كل 24 ساعة. لا توجد شهادة Authenticode، وقد يظهر تحذير SmartScreen. اختُبر البرنامج على Windows 11 Pro x64 فقط.
