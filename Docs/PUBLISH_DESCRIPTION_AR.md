# ProTech Windows Care 3.3.1 — Portable Preview

**صيانة وتحسين Windows — نسخة محمولة Portable تعمل دون الحاجة إلى التثبيت.**

شغّل `ProTech_Windows_Care_Setup.exe` مباشرة من الكمبيوتر أو USB. التثبيت اختياري فقط عبر `--setup-ui`.

**تحسينات الواجهة في هذا الإصدار:** إصلاح الأزرار المختفية، عرض شريط الأوامر في عدة صفوف حسب حجم الشاشة، تحسين ترتيب الأزرار الملونة وأيقوناتها، إصلاح عدّاد التحديد العربي، توسيع القائمة الجانبية، وتنسيق التقارير واختصارات الصفحة الرئيسية.

**الوظائف المتوفرة:** فحص الأجهزة والخدمات والتحديثات وBIOS/BSOD، معاينة آثار الصيانة، تحديد الكل وعكس التحديد، إدارة خطط WinGet وAppX الاختيارية، سجل التنفيذ والنسخ الاحتياطي. أي تغيير مدعوم يحتاج موافقة المستخدم ونسخة تحقق SHA-256 ونقطة استعادة Windows جديدة قبل التنفيذ.

**حالة الجودة:** Portable Preview تم اختبار الواجهة على 980×620 و1280×800 و1592×829 و1920×1080 على Windows 11 Pro x64. لم يتم بعد التحقق من التحديث/الحذف الفعليين على VM مستقل؛ بيانات التطبيقات المحذوفة غير مضمونة الاستعادة. Windows 10 وARM64 غير معتمدين.
