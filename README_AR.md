# ProTech Windows Care 3.3.1 — Portable Preview

**يمكن تشغيل البرنامج Portable مباشرة دون الحاجة إلى التثبيت.**

حمّل الملف الواحد `ProTech_Windows_Care_Setup.exe` وشغّله من سطح المكتب أو USB. التثبيت غير مطلوب. لا تستخدم `--setup-ui` إلا إذا أردت التثبيت الاختياري.

## التحسينات الجديدة في 3.3.1

- **حل مشكلة الأزرار المخفية:** شريط العمليات يتوزع تلقائيًا على عدة صفوف، ويعيد ضبط ارتفاعه عند تكبير النافذة أو تصغيرها، ويتوفر التمرير الداخلي عند ضيق المساحة.
- **حل تشوه النص العربي:** إصلاح الترميز الخاطئ في عداد العناصر المحددة، وإظهار «المحدد: X / Y» بشكل صحيح.
- **تحسين القائمة الجانبية:** توسيع القائمة، تحديد ارتفاع ثابت مناسب لكل قسم، إضافة هوامش لتجنب قص العناوين، وتحسين تمييز القسم الحالي.
- **أيقونات واضحة:** رسم أيقونات الأوامر بواسطة GDI+ بدل رموز الخط التي كانت تظهر مربعات أو علامات غير واضحة، مع ألوان حسب الوظيفة.
- **تحسين توزع المساحة:** تخصيص مساحة مناسبة لعنوان القسم والشرح والأزرار والجدول في النوافذ الصغيرة والكبيرة.
- **تدقيق وظائف الأزرار:** تصحيح تعليمات كانت متلاصقة في الصفحة الرئيسية والأعطال والتقارير، مع الحفاظ على أزرار التحديد الجماعي وحفظ المهمة والمعاينة والنسخ الاحتياطي والتنفيذ والإلغاء والتراجع.

## استخدام البرنامج
استخدم قائمة الأقسام في اليمين، ثم حدد العناصر المطلوبة أو اضغط «تحديد الكل». تحافظ الحماية على العناصر النظامية غير القابلة للتغيير. عند اختيار تحديث أو حذف مُتاح، تظهر معاينة العناصر وآثارها؛ يتطلب التنفيذ نسخة احتياطية متحققًا منها، وموافقة المستخدم، وصلاحية Administrator من Windows، وإنشاء نقطة Restore Point جديدة متحقق منها قبل أي تعديل. ينفّذ المحرك العناصر بالتسلسل عبر Windows PowerShell ويسجل النتائج.

**تنبيه:** لا تضمن Restore Point استعادة بيانات التطبيقات المحذوفة. قد يمنع Windows PowerShell إنشاء نقطة جديدة خلال 24 ساعة من نقطة سابقة، وعندها يتوقف التنفيذ بدل تجاوز الشرط.

## التشغيل
- Portable افتراضيًا: `ProTech_Windows_Care_Setup.exe`

- فحص الحزمة: `ProTech_Windows_Care_Setup.exe --portable-selftest`
