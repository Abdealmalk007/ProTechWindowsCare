# ProTech Windows Care 3.3.0 — Portable Preview

**هذا البرنامج Portable ويعمل مباشرة دون الحاجة إلى التثبيت.**

شغّل `ProTech_Windows_Care_Setup.exe` مباشرة من سطح المكتب أو USB. وضع التثبيت اختياري عبر `--setup-ui`، والتشغيل المحمول هو الوضع الافتراضي. يعتمد البرنامج على Windows PowerShell 5.1 و.NET Framework المدمجين في Windows؛ يضم EXE جميع ملفات ProTech التي يحتاجها.

## الجديد في 3.3
- **تحديد الكل**: يحدد العناصر الاختيارية المتاحة في القسم فقط، ولا يحدد العناصر المحمية. أزرار إلغاء التحديد وعكسه وعدّاد للعناصر المحددة.
- **أزرار عملية ذات أيقونات وألوان**: للتثبيت والتحديث والحذف والحفظ والمعاينة والنسخ الاحتياطي والتنفيذ والإلغاء والتراجع.
- **WinGet**: يمكن تحديد عدة برامج من الكتالوج المعتمد ثم النقر على Install / Upgrade / Uninstall، أو حفظ دفعة تحديث من زر Save Plan. يتم إنشاء خطة للأسماء المختارة وتنفيذها بالتسلسل عبر عملية PowerShell بصلاحيات Administrator بعد الموافقات.
- **AppX**: الحذف الفعلي يقتصر على 11 حزمة اختيارية في قائمة سماح؛ لا يحذف حزم Windows المحمية أو التطبيقات لجميع المستخدمين.
- **قبل التنفيذ**: معاينة لكل عنصر توضح ما سيتغير والمخاطر؛ نسخة احتياطية موقعة ببصمة SHA-256 ثم موافقتان مستقلتان، ثم نقطة Windows System Restore **جديدة ومتحقق منها** قبل تنفيذ أول عملية تعديل.
- **السجل والإلغاء**: نتائج مفصّلة لكل عنصر، Progress، Cancel يوقف العناصر التالية عند نقطة آمنة؛ العملية الجارية قد لا يمكن إيقافها دون فساد. لا يعيد المحرك تنفيذ دفعة مكتملة.
- **Undo**: متاح عندما تتوفر استعادة مدعومة ومتحقق منها. تحديث وحذف WinGet/AppX **ليس له تراجع تلقائي مضمون**؛ قد تضيع إعدادات وبيانات التطبيق.

## استخدام التحديث والحذف الجماعي

1. افتح قسم البرامج `Install`، أو التطبيقات الاختيارية `Apps`.
2. اختر البنود واحدًا واحدًا أو اضغط **تحديد الكل**. استخدم فلتر التطبيقات المحمية لمراجعتها دون تمكين الحذف.
3. اضغط **Upgrade / Update** لتحديث المحدد، أو **Uninstall / Remove** للحذف. يمكنك الضغط على Preview لمراجعة النتائج قبل التنفيذ.
4. يعرض البرنامج تفاصيل التعديل واحتمالات فقد البيانات. إذا وافقت، يتحقق من نسخة احتياطية للدفعة.
5. يطلب Windows صلاحية Administrator عبر UAC لبدء PowerShell. ينشئ `Checkpoint-Computer` نقطة استعادة جديدة، ويتحقق منها؛ ثم ينفذ كل بند على حدة ويسجل النتيجة.
6. إذا تعذر إنشاء النقطة لأي سبب فلا يبدأ التحديث أو الحذف. إذا فشل بند أثناء التنفيذ يتوقف عن تنفيذ البنود المتبقية وتظهر حالة FAILED / PARTIAL بدل نجاح وهمي.

**تنبيه عن Restore Point:** يفرض Windows PowerShell 5.1 عادة نقطة استعادة واحدة خلال 24 ساعة. لا يجوز تجاوز القيد تلقائيًا. System Restore لا تضمن استعادة ملفات التطبيقات المحذوفة أو جميع إعداداتها؛ لذلك تحتاج عمليات حذف البرامج موافقة مخاطرة إضافية. تحديثات برامج WinGet تتطلب اتصال الإنترنت وموافقة مصدر التثبيت. التحديثات أو الحذف الحقيقيان لم يُجربا في بيئة VM في هذا الإصدار، ولهذا يجب التعامل مع الميزة كتجريبية وعدم استعمالها على أجهزة إنتاج قبل اعتمادها.

## خيارات التشغيل
- تشغيل مباشر دون تثبيت: `ProTech_Windows_Care_Setup.exe`
- تثبيت اختياري لحساب المستخدم: `ProTech_Windows_Care_Setup.exe --setup-ui`
- اختبار ذاتي للموارد: `ProTech_Windows_Care_Setup.exe --portable-selftest`
