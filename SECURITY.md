# Security and distribution

Only download official assets from the v3.3.1 GitHub Release and verify SHA256 using SHA256SUMS.txt. The Portable executable and Setup wrapper are **unsigned**. This is a Preview, not Stable. Do not use destructive operations on production machines. Windows System Restore cannot guarantee recovery of application data. Use independent backups.

The Setup wrapper invokes --setup-ui using the exact same portable application. Its payload was verified byte-for-byte by SHA256, but interactive installation has not been VM-tested.
